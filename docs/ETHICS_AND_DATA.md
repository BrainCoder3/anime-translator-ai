# Ethics, copyright and data

Not legal advice; check the rules that apply to you.

**Copyright.** The original development used commercial anime episodes. No episode, extracted audio, dubbed video
or transcript is in this repository (`.gitignore` excludes media). `data/audit_v15_5_sanitized.json` holds numbers
only. Published experiments should use openly licensed speech or the author's own recordings.

**Voice cloning.** It can be misused for impersonation. This work only synthesises fictional characters, privately,
for evaluation. Never clone a real person's voice without consent, and label synthetic audio as synthetic.

**Models.** faster-whisper/Whisper, pyannote, Chatterbox, CosyVoice and Qwen each have their own licence and, for
some, access terms. Read them; none is redistributed here.

**Listening tests.** Keep them anonymous and voluntary, and report how many people took part.

**Secrets.** The Hugging Face token is read from the `HF_TOKEN` environment variable and never stored.
